# Установка Кворума

Эта инструкция для Claude Code или Codex, которому пользователь поручил установить навык
Если пользователь только просит прочитать или оценить репозиторий, ничего не устанавливай

## Что сделать

1. Прочитай README.md, scripts/install.py и skills/quorum/SKILL.md
2. Определи текущий инструмент: Codex или Claude Code
   Если пользователь явно просит оба — выбери both, если среда неизвестна — уточни один раз
3. Скачай этот репозиторий в отдельную локальную папку, не внутрь другого навыка
   Можно использовать git clone --depth 1 https://github.com/maksimryabkin/ai-skills.git
4. Для персональной установки выполни из репозитория:

```sh
python3 scripts/install.py --target codex
```

Для Claude Code замени codex на claude, для обоих — both
Если команда python3 отсутствует, используй установленный Python 3 через python или py -3, не устанавливай сторонние зависимости
По умолчанию устанавливается только quorum, остальные навыки автоматически не подключаются

5. Прочитай установленный SKILL.md и проверь наличие references и agents/openai.yaml
6. Сообщи точную папку и способ вызова: $quorum для Codex, /quorum для Claude Code
   Если клиент еще не обнаружил навык, предложи открыть новый чат или перезапустить клиент

## Установка только для проекта

Только когда пользователь выбрал проектную установку, добавь --scope project и точный --project-dir

```sh
python3 scripts/install.py --target codex --scope project --project-dir /path/to/project
```

## Обновление

Для обновления уже установленного нами навыка добавь --update
Установщик проверяет, что существующая папка принадлежит этому репозиторию и не изменена вручную
При конфликте покажи его пользователю, не удаляй и не перезаписывай чужой навык
Не меняй config.toml, CLAUDE.md, AGENTS.md, MCP и параметры разрешений ради установки
Не запускай проверочный совет без отдельной задачи пользователя
