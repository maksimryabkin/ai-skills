# Проверки

## Установщик

```sh
python3 -m unittest discover -s tests -v
```

Проверяется установка полного одинакового навыка для обоих клиентов, повторный запуск, сохранение чужого навыка и ручных правок, обновление своей неизмененной версии и защита от перенаправления через symlink
Python 3, только стандартная библиотека, платные API не используются

## Навык

Проведен короткий живой разбор в Codex: пять настоящих независимых субагентов получили один бриф и отдельные роли
Синтетический пример — учет выдач волонтерской библиотеки, выбор таблицы с формой или собственного приложения, ограниченные время и бюджет
Все пять разборов получены, вывод основан на ограничениях и проверке причины пропусков, а не на голосовании
Оптимист не был обязан защищать приложение, искусственный спор не создавался
Первый шаг в синтезе — небольшой пилот с учетом всех затрат времени и условием пересмотра решения
Это проверка выполнения процесса, не измерение превосходства над обычным ответом модели

Для Claude Code проверены структура навыка и путь установки по официальной документации
