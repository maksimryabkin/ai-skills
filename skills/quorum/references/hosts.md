# Среда запуска

Сначала используй фактически доступные инструменты текущего чата
Наличие SKILL.md не создает инструмент субагентов, права или подписку

## Codex

Навык устанавливается в ~/.agents/skills/quorum или .agents/skills/quorum внутри выбранного проекта
Явный вызов: $quorum, либо просьба «Созови Кворум»

Используй штатные инструменты создания субагента, ожидания и получения результата
Эти инструкции навыка прямо требуют независимого делегирования, когда оно доступно и разрешено текущей средой
При выборе модели соблюдай настройки и бюджет пользователя, не назначай всем максимальный reasoning автоматически
Создавай свежие контексты без результатов других ролей
Не используй создание обычных пользовательских чатов как замену делегированию
Если доступно только три параллельных слота, запусти трех советников, дождись завершения, затем оставшихся двух
Сохрани один бриф для обеих волн

## Claude Code

Навык устанавливается в ~/.claude/skills/quorum или .claude/skills/quorum внутри выбранного проекта
Явный вызов: /quorum, либо просьба «Созови Кворум»

Координируй из основного чата через штатный инструмент Agent и доступные read-only/general-purpose субагенты
Не запускай сам Кворум в context: fork, если получившийся дочерний агент не может создавать своих субагентов
Передавай бриф и нужную роль явно: родительский контекст может наследоваться по-разному в разных версиях
Не включай agent teams, не устанавливай MCP-сервер и не меняй разрешения для этого навыка

## Если возможности отличаются

Сохрани одинаковую логику вопроса, ролей, проверки и синтеза
Адаптируй только вызовы инструментов к текущему клиенту
Не запускай вложенный платный CLI или API как скрытую замену отсутствующим субагентам
Для одноагентного разбора сначала обозначь ограничение и получи согласие пользователя
