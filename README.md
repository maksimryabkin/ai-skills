# Навыки Максима Рябкина

Один репозиторий для Claude Code и Codex

## Кворум

Пять агентов независимо разбирают твое решение, затем собирают рекомендацию и способ проверить ее на практике

Например: нанять помощника или автоматизировать задачу, запускать продукт сейчас или сначала проверить спрос, выбрать один из нескольких планов

### Как установить

Вставь в Claude Code или Codex:

```text
Установи мне Кворум из https://github.com/maksimryabkin/ai-skills
Прочитай INSTALL.md, установи навык для текущего инструмента и проверь установку
```

Помощник сам скачает репозиторий и положит навык в нужную папку
Никаких API-ключей или отдельных серверов для навыка не нужно

### Как пользоваться

```text
Созови Кворум
Я выбираю между [вариант А] и [вариант Б]
Хочу получить [результат]
У меня есть [время, деньги и другие ограничения]
Вот что уже известно: [факты]
```

Можно просто написать «Спроси совет» или вызвать `/quorum` в Claude Code и `$quorum` в Codex

**Короткий режим** — пять независимых разборов и общий вывод

**Полный режим** — к ним добавляются пять анонимных рецензентов, которые ищут слабые аргументы и общие слепые зоны
Попроси «полный Кворум», если нужен этот дополнительный раунд

### Что получишь

- Конкретную рекомендацию с обоснованием
- Слабое допущение, которое могло остаться незамеченным
- Существенное разногласие, если оно есть
- Небольшой проверочный шаг с понятным результатом
- Условие, при котором решение стоит пересмотреть

### Чем полезен

Кворум сравнивает основания выводов, а не выбирает ответ большинством голосов
Агенты получают одинаковую задачу и не видят ответы друг друга до проверки
Короткий режим не запускает дорогой второй раунд автоматически
Если субагенты недоступны, помощник скажет об этом и предложит другой формат

Навык бесплатный, работа агентов расходует лимиты твоего Claude или Codex
Для независимого совета нужны доступные в твоем клиенте субагенты
Кворум помогает рассуждать, но не гарантирует правильность ответа
